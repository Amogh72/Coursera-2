\# Cars Dealership



A responsive full-stack web application for Cars Dealership, a national car

retailer in the United States.



\## Project Name



\*\*Cars Dealership\*\* — dealership locator and review platform



\## Overview



Cars Dealership lets customers browse dealership branches nationwide, filter

them by state, view dealer details, and read and post reviews for any branch.

Dealers and car makes/models are managed through the Django admin console.



\## Tech Stack



\- \*\*Backend:\*\* Django (Python), Django REST Framework, SQLite

\- \*\*Frontend:\*\* React, Bootstrap

\- \*\*Deployment:\*\* Docker, Kubernetes, IBM Cloud Code Engine

\- \*\*CI/CD:\*\* GitHub Actions



\## Features



\- User registration, login, and logout

\- Browse all dealerships, or filter by state

\- View dealer details and existing reviews

\- Post reviews with live sentiment analysis

\- Admin console for managing dealers, car makes, and models
